CodeAlpha Basic Chatbot

A simple rule-based chatbot developed in Python as part of the CodeAlpha internship.

📌 Project Description

This project is a basic console-based chatbot that responds to predefined user messages.

The chatbot takes input from the user and provides different responses based on the entered message.

 🤖 Features

* Responds to basic messages such as "hello" and "how are you".
* Provides predefined responses.
* Handles unknown messages.
* Continues the conversation using a loop.
* Ends the conversation when the user types "bye".

🛠️ Technologies Used

* Python
* Functions
* If-elif-else statements
* While loops
* Strings
* Console input/output

 ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

```bash
python chatbot.py
```

4. Type messages and interact with the chatbot.
5. Type `bye` to end the conversation.
